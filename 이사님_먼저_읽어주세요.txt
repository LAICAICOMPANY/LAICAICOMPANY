라이차이컴퍼니 홈페이지 리뉴얼 — 이사님 안내
=============================================

이 폴더에 새 홈페이지가 전부 들어 있습니다.
이사님 컴퓨터의 클로드코드(Claude Code)가 이 폴더를 열면, 안에 있는 CLAUDE.md 를 읽고
무엇을 해야 하는지 알아서 파악합니다.


1. 시작하는 방법
----------------
1) 이 압축 파일을 원하는 곳에 풉니다. (예: 바탕화면)
2) 압축을 푼 "라이차이_웹사이트_리뉴얼_전달" 폴더에서 클로드코드를 실행합니다.
   - 폴더 빈 곳에서 Shift + 오른쪽 클릭 → "터미널에서 열기" → claude 입력
3) 클로드코드에 아래 문장을 그대로 붙여넣습니다.

   ┌───────────────────────────────────────────────────────────
   │ CLAUDE.md 읽고, 새 홈페이지를 내 컴퓨터에서 먼저 띄워서 보여줘.
   │ 확인되면 지금 laicaicompany.com 이 올라가 있는 Netlify 에
   │ 기존 사이트 대신 이걸로 배포하는 걸 도와줘.
   │ 기존 사이트 프로젝트 폴더는 [여기에 폴더 위치] 에 있어.
   └───────────────────────────────────────────────────────────

4) 클로드코드가 단계마다 물어보면 답해 주시면 됩니다.


2. 나중에 문구나 내용을 바꾸고 싶을 때
--------------------------------------
같은 폴더에서 클로드코드를 열고 이렇게 말하면 됩니다.
   예) "서비스 목록에 '중국 SNS 광고 집행' 추가해 줘"
   예) "숫자 섹션 누적 매출을 150억으로 바꾸고 배포해 줘"
   예) "모바일에서 어떻게 보이는지 보여줘"


3. 배포 전에 알아두실 것
------------------------
- 문의 폼은 지금 사이트와 같은 Formspree 주소로 연결해 두었습니다.
  새 사이트 문의도 지금과 같은 메일함으로 들어옵니다.
- 네이버 사이트 인증 코드, 로고, 공유 이미지(og-image)도 기존 것 그대로 옮겼습니다.
- 도메인 연결은 Netlify 설정이라 바꿀 필요가 없습니다.
- 문제가 생기면 Netlify 의 Deploys 목록에서 이전 배포를 다시 선택해
  바로 예전 사이트로 되돌릴 수 있습니다.
- 배포 후 문의 폼 테스트를 1건 보내서 메일함에 들어오는지 꼭 확인해 주세요.


4. 아직 남은 일
---------------
- 클라이언트 로고 이미지 (지금은 브랜드 이름 글자로 표시)
- 메타 광고 픽셀 코드 연결 (필요하면)
- 영상 속 젠지·오뚜기 로고, 인물 사용 동의 확인
